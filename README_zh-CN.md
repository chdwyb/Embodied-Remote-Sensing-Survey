# 具身遥感综述

[English](README.md)

本仓库整理具身遥感相关的公开论文、代码、数据集与资源，涵盖地理空间理解、导航、观测规划、预测建模及协同感知。

## 研究主题

| 主题 | 研究范围 |
| --- | --- |
| 地理空间定位与理解 | 将视觉观测、语言和地理背景关联到位置与场景语义。 |
| 导航与任务执行 | 根据目标和观测形成路线、导航决策与任务动作。 |
| 自适应采集与建图 | 选择观测和建图动作，改善覆盖范围与信息质量。 |
| 面向观测与行动的预测模型 | 建模环境变化与未来观测，为行动选择提供依据。 |
| 协同感知与信息共享 | 协调多个平台，并在感知主体之间交换信息。 |

[主题目录](docs/papers.md)还收录支撑性数据集、背景概念和相关综述。每条文献列出标题、发表渠道、年份，以及可用的论文、代码或项目链接。

## 数据与引用

结构化目录见 [literature.json](data/literature.json)、[resources.json](data/resources.json) 和 [references.bib](data/references.bib)。使用相关方法或资源时，请引用对应的原始论文。外部论文、软件和数据集的授权条件以各自来源为准。
