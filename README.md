# Embodied Remote Sensing Survey

[简体中文](README_zh-CN.md)

A curated directory of papers, code, datasets and resources for embodied remote sensing. The collection connects geospatial understanding with navigation, observation planning, predictive modeling and coordinated sensing.

## Contents

- [Papers by topic](docs/papers.md)
- [Papers by publication year](docs/papers-by-year.md)

## Research topics

| Topic | Scope |
| --- | --- |
| Geospatial Grounding | Relating visual observations, language and geographic context to locations and scene semantics. |
| Navigation and Mission Execution | Turning goals and observations into routes, navigation decisions and mission actions. |
| Adaptive Acquisition and Mapping | Choosing observations and mapping actions to improve coverage and information quality. |
| Predictive Models for Observation and Action | Modeling environmental dynamics and future observations to support action selection. |
| Coordinated Sensing and Information Sharing | Coordinating platforms and exchanging information across sensing agents. |

The [topic catalogue](docs/papers.md) also includes supporting datasets, background concepts and related surveys. Each entry provides its title, publication venue, year and available paper, code or project links.

## Data and citations
